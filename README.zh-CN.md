# CS2 Demo Evidence Lab

**1.0.1** · 源码整合包；首次需要 Python 3.12（64 位）与 Node.js 24。外层 `START.cmd` 启动，`STOP.cmd` 关闭。
**用于 Counter-Strike 2 demo 分析与比赛复盘的离线工作台。**

[English](README.md) · 简体中文

将比赛录像转化为玩家统计、可复查的交战片段、闪光记录与 2D 战术回放。分析保留对应证据，并区分观测事实、估计结果和不可用数据。

采用 **Python / FastAPI** 后端和 **React / TypeScript / Vite** 前端。首次安装依赖后，分析在本地运行，无需云账号。当前应用界面以中文为主。

## 主要功能

| 功能 | 可查看的内容 |
| --- | --- |
| 比赛统计 | 玩家与回合数据、伤害、首杀首死和游戏记录的助攻。 |
| 交战与死亡复盘 | 事件时间线、相邻玩家状态、复盘标签，以及人工结论和备注。 |
| 瞄准变化 | 击杀前、死亡前及非击杀交战序列首枪前的垂直瞄准变化。 |
| 移动与射击 | 移动后首枪达标率、开枪低速达标率，支持武器范围切换与逐枪证据。 |
| 连续射击 | 瞄准轨迹采样、攻击输入观测、弹序与伤害事件关联。 |
| 闪光弹分析 | 已记录的敌人、队友和自闪影响、游戏记录的闪光助攻，以及回放跳转。 |
| 2D 战术回放 | 离线雷达底图、玩家位置与朝向、事件定位、片段收藏、备注和绘图。 |
| 个人存档 | 一个存档收录多个 SteamID，独立玩家趋势、重复比赛去重及历史快照。 |

提供浅色、深色和跟随系统主题，以及舒适、紧凑布局。默认隐藏 100% 覆盖率标签和技术明细。

## 快速开始

随附启动脚本面向 **Windows**。

**环境要求：** Python 3.12（64 位）与 Node.js 24，均需加入 PATH。

1. 下载或克隆仓库。
2. 运行 `app/setup.cmd` 安装依赖并构建前端；首次安装需要联网。
3. 运行 `app/start.cmd`，打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。
4. 导入 `.dem` 文件，分析完成后选择对应场次。
5. 使用 `app/stop.cmd` 停止本地服务。

本项目为源码发行形式，不是独立 EXE。完成依赖安装后，demo 分析与内置雷达底图均可离线使用。

## 复盘流程

先查看玩家统计，再打开交战片段或闪光记录，跳转到对应回放时刻检查位置和事件，并保存备注或书签。

需要长期追踪时，在“个人存档”中创建档案，勾选当前比赛的一个或多个 SteamID 后保存。各 ID 的指标独立保留；重复保存同一场比赛不会重复计数，保存发生变化的分析结果时会保留旧版本快照。

## 数据与限制

- **保留证据与未知状态。** 缺失观测不会补成零，估计结果和覆盖不足会明确标注。
- **闪光分析受事件完整度限制。** 缺少原生致盲事件时，符合条件的状态变化仅作为估计记录，不代表完整还原玩家看到的画面。
- **瞄准变化只描述动作。** 垂直角度变化小不等于预瞄正确；瞄准轨迹不是弹着点，也不生成缺乏依据的压枪准度评分。
- **雷达底图仅作位置参考。** 地图资源版本可能与录像不同，回放未重建精确可见性、烟雾遮挡或客户端画面。
- **人物定位和选位分析仍在规划中。** 接口已预留，模块保持禁用。

导入文件、解析缓存和个人存档保存在 `app/data/`，不提交到仓库。备份时应先停止服务，再复制该目录。保存的指标和证据快照可以独立阅读，2D 回放仍需要对应解析事实。

## 开发与验证

安装依赖后，在仓库根目录运行后端测试：

```powershell
app/.venv/Scripts/python.exe -X utf8 -m pytest app/tests -q
```

构建前端：

```powershell
npm.cmd run build --prefix app/frontend
```

后端、前端、测试和模块模板分别位于 `app/backend/`、`app/frontend/`、`app/tests/` 和 `app/module_template/`。
