# 算法与能力边界

## basic_stats

仅完整正式回合：round_start → freeze_end → 有 winner 的 round_end。cs_pre_restart 只在正常 end 前出现才视为中断；普通回合间的该事件不能误排整场。热身、截断回合另列；raw round 重复/加时通过按时间生成的 round_id 保持区分。阵营从每回合 live 起点的实体状态取得，不用最终队伍回填全场。

参与分母是 freeze_end 时存活、有非零 SteamID、属于 T/CT 的玩家；中途加入不直接增加该回合分母。零 SteamID/未匹配玩家排除。机器人接管与人机身份迁移未完成专门重建，遇到这类录像不能宣称完整竞技口径；当前样例未观察到机器人参与。存活同时要求 end 状态活着且该回合没有死亡事件。

击杀只计对敌，死亡保留自杀/队杀受害者死亡；非对敌类别另计。游戏内助攻来自 assister，闪光助攻来自 assistedflash，不重建伤害阈值助攻。多杀分布按回合统计。首杀/首死遇同 tick 多笔则不认定唯一顺序。

K/D、KPR、DPR、HS-kill% 采用各自分母，零分母 null。HS-kill% 是对敌爆头击杀/对敌击杀；头部 hurt 事件占比与头部 hurt/fire 另命名。后者包括多弹丸/穿透多目标，绝非精确子弹命中率。

伤害同时保存 raw dmg_health 和可验证 effective damage。有效封顶需要上一相邻 tick 的存活生命、事件 payload 的伤后 health、本 tick 对该受害者唯一 hurt，且 `pre_health - post_health == min(raw, pre_health)`。否则该事件 unknown，整人的有效 ADR 为 null；raw ADR 仍可复查。事件附加 user_health 绝不直接当作 pre-health。只按稳定 event_id 去除重复交付；相同数值但不同事件 ID 不随意删掉，避免把真实多弹丸当重复。

KAST_local 的 T：死亡后、严格晚于死亡 tick、配置秒数内，存活队友击杀原击杀者。默认 5 秒为本产品规则；同 tick 顺序不明不补记。其余 K/A/S 为该回合击杀、游戏内助攻、存活之一。它不等于 HLTV 官方实现。

## head_line v2：击杀前垂直瞄准变化

默认以正式回合中的对敌枪械击杀为锚点，读取击杀前 1 秒至击杀 tick 之前的状态，不用击杀 tick 末已经可能转瞄的状态。只统计存活、主副武器、同武器实例/玩家实体的连续相邻区间；缺失、切枪和实体切换处断线。每个窗口计算 pitch 的 P95−P5、最大最小差；汇总取击杀窗口中位数，单位为度。有效时长默认至少 0.5 秒，保留实际有效时长、未知/排除数、开枪/受伤标记。有效覆盖率是窗口通过率，不是把缺失角度补零后的“稳定率”。重叠击杀窗口逐击杀计数并相互标注。

AWP、电击枪、非枪械击杀排除。霰弹枪不存在本实现已校准的统一“躯干一枪致死距离”：需要弹丸、距离、血甲、部位与补丁模型。当前只有同 tick 唯一开火、唯一躯干伤害且前序血量支持单枪致死时，标记为已观察躯干一枪致死而排除；其余霰弹枪样本标为致死距离未知，暂不进入主指标，同时保留可读取的距离/血甲。不能把它说成已完成所有霰弹枪按距离精确分类。

数值小只表示垂直转角变化较少；不证明预瞄正确。高低差转瞄、压枪、跟枪都可能扩大数值；只看成功击杀也存在样本选择偏差。它不是渲染准星或客户端预测重建。

### 实验：旧几何头线视图

旧方法在 legacy.py 保留，UI 通过显式“实验：几何头线估计”切换。它基于开火附近窗口，不是击杀样本，不与默认指标合并。

先按开火序列首枪构造实验窗口 [-250,-50] ms，逐原生 tick 计算。窗口不是“首次看见敌人前”；没有地图射线/烟雾重建。运行确实调用 VisibilityProvider，它返回 unknown，因此所有几何结果归入估计区，验证头线和无目标通用预瞄为 unavailable。

眼位/头位使用带版本的线性姿态模型：默认站立 64、全蹲 46 units，按连续 duck_amount 插值。它们是实验参数，未宣称是此补丁精确骨骼或动画眼位。世界 Z 向上；CS pitch 正方向向下，数学瞄准仰角=-pitch。`a_target=atan2(H.z-E.z,hypot(dx,dy))`；垂直误差 `-pitch-a_target`，水平 yaw 误差单列。容差 `atan2(head_radius,horizontal_distance)`，随距离变化。

仅前方水平锥角内活着、地面敌人是候选；排除自己死亡、空中、换弹、非枪械和非普通 move_type=2。v2.1.1 不再根据 flash_duration 峰值排除致盲：该字段不是实时剩余致盲秒数，实时致盲状态保留 unknown；flash_exclude_seconds 仅兼容旧配置。该 move type 的适用性仍需更多补丁验证。多目标先按距离、再 SteamID 选择，保存全部候选和歧义；不使用事后受害者或“最靠近准星”来选择。无候选不评价，不能据此惩罚跑图。

范围内/偏高/偏低按真实连续观测 dt 加权；分位数也用 dt 权重。不同自己/目标姿态有独立结果。精确眼位、动画头骨、坡道姿态、可见性与客户端预测尚未验证；低估计比率不是玩家技能判决。

## stop_shooting

`is_airborne` 与运动状态单列。位置速度为相邻连续 tick 平面位移/实际 dt；排除断裂、死亡重生、玩家实体变化、回合/队伍变化和异常位移。原生 alias velocity 在样例实测对应前一个位置区间，故不使用其值冒充当前速度。

每枪保留 t-2→t-1 与 t-1→t 两个区间平均速度。两者都低于武器参考阈值-模糊带，记 ready；都高于阈值+模糊带，记 moving；跨阈值/临界/缺失为 ambiguous/unknown。同 tick 多枪、切枪/重装边界不强行判定；空中/非配置枪械 excluded。两个平均值不是瞬时速度上下界，因此 ready 仍只是代理。

武器配置在 `providers/weapons.json`，包含 34 种枪械与来源 blob SHA。参考阈值 = 武器最大移动速度 × 34% × threshold_scale；对有瞄准镜武器选择相应开镜参数，开镜状态未知时不判定。34% 引用 Leetify 公开统计规则，最大速度来自 GameTracking-CS2 的 weapons.vdata；并不宣称与当前 demo 补丁完全匹配或消除了所有不准确因素。默认 ±5 units/s 模糊带与移动滞回仍是产品实验参数。accuracy_penalty 不解释为纯移动误差。

默认“移动后首枪达标率”，可切换“开枪低速达标率”。同时计算 weapon_set=all 与 exclude_run_and_gun 两组；后者去掉全部冲锋枪、霰弹枪，以及除沙鹰外全部手枪（含 R8）。速度达标枪 / 可判定枪是两种口径各自的比率。无有效分母显示 null；全场结果、武器分组、未知/排除数和证据引用分别保留，API 在分页前按范围过滤。

移动段：默认回看 600ms、进入速度>阈值×1.25、退出速度<阈值、至少80ms；滞回减少抖动。先前开枪在该运动段起点之前时，本枪才作为该运动段后的首枪；连续扫射后续枪不重复记为急停首枪。原地射击进入全部枪统计，但不会进入移动后首枪分母。回看区间必须保持连续、存活、地面和同武器；不完整时将首枪资格标为 unknown，不算作失败。满足低速后的等待时间在有连续证据时输出，误差至少一个 tick。无输入证据，不判断反向键。

## recoil_control

按玩家、回合、武器实例/类型、弹药上升（换弹）、shots_fired 重置、射击模式变化、实体变化和武器实验恢复间隔切分。至少4枪为默认展示门槛；自动枪序列与其他枪型分别标识，不假定所有序列都是自动扫射。

事件窗内受伤、姿态大变、空中/运动数据缺失、同tick/实例边界不清的序列不进入稳定描述统计，仍保留原因。视角轨迹包含逐 tick 的 pitch/yaw，另保留每枪前一个 tick 末的原始状态。二维瞄准路径以左右相对角/上下相对角等比例绘制，并标记开枪/受伤；不画成弹着点。raw AimPunch base 和 recoil index 仅旁列。

读取 FIRE 与 usercmd_buttonstate_1 的攻击位；只有整个射击区间逐 tick 都有效、同武器/实体且两个字段一致为真，才标记 continuous_attack_samples；观测到一致的松开为 intermittent_attack_samples；缺失/不一致/断裂为 unknown。这些是网络攻击输入的观测标签，不证明物理左键始终按下，不声称已重建 subtick 输入。UI 可筛选三种证据，顶部指标保持完整序列分母。当前未还原有效 P，也未证明 V 是否已包含 punch；没有再次乘2或相加。不能可靠检测换目标，不能声称扣除了跟枪贡献。

生产输出为 B 层：可描述序列数、视角 pitch 变化的分布/中位数及弹序曲线。有效补偿残差、真实落点散布均 NULL。公式 helper `wrap(ΔV+ΔP-ΔT)` 只在合成、已知有效 P 的测试中验证；这些测试不构成此 demo 的压枪成绩。理想/不补偿/过补偿/目标运动/跨180度测试用于避免未来实现公式错误。

## 共同约束

事实常量（角度转换/哈希/字段枚举）、产品实验阈值（窗口/几何/速度/恢复）、用户参数分别记录。每项结果带参数快照、算法/parser/provider 身份、分子分母、未知和排除数、覆盖率及证据。小样本只提示，不生成 tick 独立假设下的狭窄置信区间。没有职业百分位或官方 Rating/Impact/Round Swing。planned 三个模块的 README、analyzer、业务 schema properties 和 description 都为空。
