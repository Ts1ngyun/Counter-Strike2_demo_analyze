# 复盘、闪光与多 ID 存档 · 2026-10-24

本次加入 2D 战术回放、交战与死亡复盘、闪光弹分析、瞄准变化的更多观察窗口，以及个人存档。人物定位、选位仍是两个禁用的 planned 接口。

## 怎么使用

1. 导入 demo，或对旧任务点“重试 / 复用缓存”，生成新增模块结果。
2. “交战与死亡复盘”按情形标签排列片段，可筛选玩家与回合、查看双方状态和事件时间线、记录人工结论与备注。标签安排复盘顺序，不自动判错。
3. “闪光弹分析”按颗查看敌人、队友、自闪、爆开后击杀关联，以及游戏记录的闪光助攻。点击回放按钮直接定位对应 tick。
4. “2D 战术回放”可播放、逐 tick 定位、查看人物方向和生命，收藏片段、写备注或画线。书签按 demo 哈希共享，重算不会丢失。
5. “交战瞄准变化”可分别观察击杀前、死亡前、非击杀交战窗口；证据中拆分首枪前调整与开火阶段。连续射击增加弹序与伤害事件对照、受伤对象运动采样说明。

回合筛选作用于复盘卡片和证据；汇总指标保留完整比赛分母。原有明暗主题、隐藏 100% 覆盖率和可选技术明细继续有效。

## 一个存档容纳多个 SteamID

进入“个人存档”，创建或选择存档，在“收录当前比赛”勾选多个玩家后保存。同一个 ID 也能保存到不同存档。不同 ID、算法版本、参数、武器范围及实现身份分别生成趋势，不混为一条曲线。

同一存档内，相同 demo 哈希与 SteamID 只占一条当前记录。重复保存完全相同结果不增加比赛次数或版本；保存重算后的不同结果保留旧快照，只让最新版参加趋势。趋势按保存时间排列；比率合并总分子与总分母，不简单平均百分比；中位数不冒充跨场总体中位数。

“查看快照”可以切换历史版本。保存时会收录该 ID 的指标、证据及当时的人工标注和书签；全场共享书签另列。新增备注后需要再次保存。快照不随原任务自动变化，原任务被清理后仍能阅读；2D 回放仍需要原始解析事实。

“移出趋势”可以从已隐藏记录恢复。支持 JSON 导出；当前不提供 JSON 导入入口。页面提供“示例存档 · NiKo 与 m0NESY”用于当前开发电脑验收，发行源码包不携带该存档或其他运行数据。

## 数据边界

- 这份 demo 没有原生 `player_blind` 事件。闪光分析仅将相邻同玩家实体的新 `flash_duration` 正值变化与唯一同 tick 爆开关联，标成估计。该字段是峰值记录，不能累加成致盲时长，也不能据此认定当前仍被闪。
- 91 颗闪中，71 颗有可关联的新状态变化；45 颗记录敌人影响、35 颗记录队友影响、28 颗记录自闪，类别可以重叠。另有 7 次游戏记录的闪光助攻。没有变化的样本不写成“零影响”；91 颗都不宣称受影响名单完整。
- 爆开后时间窗内的击杀只是关联，不认定闪光导致击杀。没有精确客户端白屏、遮挡和可见性重建。
- 雷达底图随包离线提供，资源补丁与这份录像的匹配尚未验证，只作布局参考。可改用世界坐标或自行导入并校准底图。来源和版权见 `frontend/public/maps/NOTICE.txt`。
- 瞄准变化不是预瞄正确率；瞄准路径不是弹着点。AWP、电击枪与未能校准躯干致死距离的霰弹枪样本仍依规则排除或标未知。压枪不生成缺乏依据的准度评分。

## 验证与开发接入

真实 demo：`2398717_8244_2.dem`，Anubis，10 名玩家、20 个完整正式回合，Falcons 13 / TYLOO 7。

最终验证任务：`cf8d172fcd834a7da4627478a106b797`。六个启用模块均无运行失败；部分能力标为 partial 是保留缺失或估计信息。完整记录见 [review-v3-validation.json](review-v3-validation.json)。复用事实缓存并重算瞄准模块用时 31.7 秒，不能作为首次导入时间。

140 项自动化测试通过，覆盖算法、接口、档案多 ID 隔离、去重、历史版本、隐藏恢复及证据保留；前端通过 TypeScript 和 Vite 构建。浏览器验证了闪光跳转至 r003 / tick 14653、同档案两 ID 保存、重复保存不增计数以及历史快照读取。测试时有一条 Starlette/httpx 兼容弃用提醒，不影响当前测试；后续依赖升级需一并处理。

详见 [回放接口与限制](REPLAY.md)、[交战及瞄准模块](COMBAT_REVIEW.md)、[合作伙伴交接](PARTNER_HANDOFF.md)。存档 API 在 `backend/routers/profiles.py`；文件为 `data/profiles.sqlite`，标注位于 `data/review/`，书签位于 `data/replay/`。备份运行资料时先停止服务，再备份整个 `app/data`；源码交接包排除运行资料。
